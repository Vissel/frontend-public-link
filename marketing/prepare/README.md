# PublicLink Zero-Cost Marketing Kit - Index

A **0đ (no ad spend)**, pure-organic marketing kit for **PublicLink** (`share-link.top`) - the fastest way
for Vietnamese sellers to turn one link + one QR into orders. Audience: **sellers (primary)** and
**buyers (secondary)**. Strategy is **phased**: awareness first, then conversion.

All customer-facing copy is in **Vietnamese**. Structural notes/labels are in English.

## How to run this kit

1. **Do `prepare/` first** (a few hours, before Day 1). Everything you post references assets built here.
2. **Then execute one folder per day**: `day1/` -> `day56/` (8 weeks). Open the day's `dayN.md`, do the tasks,
   copy-paste the Vietnamese post, log the KPI, move on. Each day is ~30-60 minutes of work.

## What is in `prepare/`

| File | Purpose |
|------|---------|
| `00-strategy.md` | Master plan: positioning/USP, personas, channel ranking, phases mapped to the 56 days, posting hours, referral loop, $0 tools, KPIs. |
| `setup-checklist.md` | Phase 0: create/optimize every channel + add the "Powered by PublicLink" referral CTA. |
| `brand-and-assets.md` | Brand kit (blue `#0f4c81`, logo, domain, contact), reusable caption/CTA blocks, UTM link template, GA4 notes. |
| `video-1-product-link.md` | Full script for the **product-link** short (no person, UI-only). |
| `video-2-yoga-booking.md` | Full script for the **yoga-booking** short (no person, UI-only). |
| `video-production-guide.md` | $0 production workflow (screen-record + CapCut + free music), export specs, repurposing map. |
| `master-calendar.md` | One-screen 56-day overview (phase, platform, time, pillar, topic, asset, CTA, KPI). |
| `post-templates.md` | Reusable Vietnamese copy bank that every day adapts from. |

## The one message to remember

> **Tạo 1 link. Nhận đơn / giữ chỗ. Tiền về thẳng tài khoản của bạn. Chỉ 10.000đ / 3 ngày.**
